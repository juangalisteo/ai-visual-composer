# Official Assets

This directory contains official product assets for AI Visual Composer.

These assets are intentionally versioned because they are part of the current product behavior. They are not local runtime dependencies, generated outputs, model files, checkpoints, or private development resources.

## Asset Governance

- Official product assets may be committed when they are required by the product.
- Asset size alone is not a reason to remove an official asset while repository size remains reasonable for the project.
- Future overlays may be committed when they become official product assets.
- Development-only assets, local experiments, generated media, AI models, checkpoints, LoRAs, VAE files, embeddings, ControlNet resources, external runtimes, logs, and local outputs must remain outside the public repository.
- New assets must have confirmed provenance and conditions of use before being committed.
- Every new official asset added to the project must document its provenance, license, or conditions of use when it is added to the repository.

This policy applies to all official project assets, including music, fonts, images, videos, overlays, visual effects, graphic resources, and any other official asset incorporated into the project.
