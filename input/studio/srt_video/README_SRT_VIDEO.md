# STUDIO — SRT + VIDEO

Carpeta de entrada del modo SRT + VIDEO: pinta tu SRT sobre el vídeo.

- Pon aquí un vídeo `.mp4` y un `.srt` en UTF-8. Si hay varios, el programa
  pregunta cuáles.
- El SRT se pinta tal cual (mismo texto y mismos tiempos); el perfil de
  subtítulos solo pone el aspecto.
- Para corregir un vídeo de SOLO VIDEO, trae aquí el SRT que se pintó,
  `<proyecto>_<modo>.srt`, no `<proyecto>.srt`.

Cómo se usa: [docs/START.md, SRT + VIDEO](../../../docs/START.md#72-srt--video).
