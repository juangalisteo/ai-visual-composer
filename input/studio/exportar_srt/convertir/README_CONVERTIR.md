# STUDIO — EXPORTAR SRT ➜  VIDEO: CONVERTIR

Carpeta de entrada de CONVERTIR: corta un SRT en líneas según un perfil de
subtítulos. No hace ningún vídeo.

- Pon aquí un `.srt` en UTF-8. Si hay varios, el programa pregunta cuál.
- El estilo se elige en los menús FORMATO y SUBTÍTULOS → FAMILIA → PERFIL. Tu
  SRT no cambia: sale uno nuevo en `output/<proyecto>/subtitles/`.

Cómo se usa: [docs/START.md, EXPORTAR SRT ➜  VIDEO](../../../../docs/START.md#76-exportar-srt---video).
