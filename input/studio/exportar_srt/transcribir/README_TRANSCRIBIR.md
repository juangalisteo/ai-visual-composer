# STUDIO — EXPORTAR SRT ➜  VIDEO: TRANSCRIBIR

Carpeta de entrada de TRANSCRIBIR: saca un SRT con lo que se dice en un vídeo o
en un audio. No hace ningún vídeo.

- Pon aquí un `.mp4` o un `.mp3`. Si hay varios, el programa pregunta cuál.
- Whisper lo transcribe; el SRT sale en `output/<proyecto>/subtitles/<proyecto>.srt`.

Cómo se usa: [docs/START.md, EXPORTAR SRT ➜  VIDEO](../../../../docs/START.md#76-exportar-srt---video).
