# STUDIO — MONTAJE VÍDEOS

Carpeta de entrada del modo MONTAJE VÍDEOS: une varios vídeos en el orden que
elijas.

- Pon aquí dos o más vídeos `.mp4`.
- El programa los numera y pide el orden, por ejemplo `2 1 3`. El montaje no
  lleva subtítulos.

Cómo se usa: [docs/START.md, MONTAJE VÍDEOS](../../../docs/START.md#74-montaje-vídeos).
