# STUDIO — INTRO / OUTRO

Carpeta de entrada del modo INTRO / OUTRO: añade una intro, un outro o los dos
a un vídeo tuyo.

- Pon aquí el vídeo `.mp4`, directamente, sin subcarpetas. Si hay varios, el
  programa pregunta cuál.
- Las intros y los outros no van aquí: van en
  `assets/videos/intro_outro/vertical/` o `assets/videos/intro_outro/horizontal/`
  (según el formato), cada una con sus carpetas `intro/` y `outro/`.

Cómo se usa: [docs/START.md, INTRO / OUTRO](../../../docs/START.md#73-intro--outro).
