# STUDIO — SOLO VIDEO

Carpeta de entrada del modo SOLO VIDEO: subtitula un vídeo a partir de su
propio audio.

- Pon aquí un vídeo `.mp4` con audio. Si hay varios, el programa pregunta cuál.
- Whisper transcribe el audio; el estilo de los subtítulos se elige en el menú
  SUBTÍTULOS → FAMILIA → PERFIL.

Cómo se usa: [docs/START.md, SOLO VIDEO](../../../docs/START.md#71-solo-video).
